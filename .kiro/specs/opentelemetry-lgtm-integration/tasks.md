# 實作計劃: OpenTelemetry LGTM 整合

## 概覽

將 OpenTelemetry 整合到現有的 Spring Boot 微服務系統中，並建立完整的 LGTM 可觀測性堆疊。實作將採用 OpenTelemetry Java Agent 進行自動儀表化，並透過 OpenTelemetry Collector 將數據路由到 Mimir、Tempo、Loki 和 Grafana。
